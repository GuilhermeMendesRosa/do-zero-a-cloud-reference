# Do Zero à Cloud

Material de planejamento e, futuramente, código-base do workshop **Do Zero à
Cloud: construindo e publicando uma API com Spring Boot**.

O workshop foi pensado para duas aulas:

1. fundamentos de backend e implementação local de uma API REST;
2. fundamentos de cloud e publicação da aplicação no Railway.

O planejamento completo está em
[docs/plano-workshop-do-zero-a-cloud.md](docs/plano-workshop-do-zero-a-cloud.md).
